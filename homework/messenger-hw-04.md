# Домашнее задание 4 — Улучшение UX

## Блок А — Улучшение UX

### А1 — Обратная связь после регистрации

Сейчас после `signUp` ничего не происходит — форма просто остаётся на месте, пользователь не понимает, сработало ли действие.

Нужно: после успешной регистрации показывать состояние вида «Проверьте почту для подтверждения» вместо формы логина/регистрации. Пользователь переходит по ссылке из письма в новой вкладке — и там уже всё отрабатывает нормально.

### А2 — Шапка чата

Сейчас в шапке — только email собеседника и кнопка «Выйти». Нужно сделать лучше (обсудить на уроке, что именно: возможно свой email/аватар, статус, кнопка назад к списку и т.д.).

### А3 — Явные состояния чата

Сейчас два разных состояния визуально не различаются и оба выглядят слабо:

1. Собеседник не выбран вообще («выберите собеседника»).
2. Собеседник выбран, но переписки с ним ещё нет (пустой чат).

Нужно сделать для них разные, понятные состояния UI.

### А4 — ID собеседника в URL

Сейчас выбранный собеседник хранится только в состоянии компонента (`useState`) — при перезагрузке страницы выбор теряется, приходится искать пользователя заново.

Нужно: хранить id собеседника в URL (например `/chat/:receiverId`), чтобы при перезагрузке страницы переписка восстанавливалась автоматически.
